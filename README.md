# X-ONE Furniture Website

## Deskripsi Proyek

Proyek ini merupakan pengembangan sebuah website perusahaan furnitur bernama **X-ONE Furniture**. 
Website ini dikembangkan menggunakan PHP, Bootstrap, dan beberapa teknologi web pendukung lainnya 
untuk menciptakan tampilan yang responsif dan user-friendly.

## Fitur Website

### 1. Halaman Beranda
- Menampilkan carousel gambar produk.
- Hero section dengan pengantar singkat tentang X-ONE Furniture.
- Informasi layanan unggulan seperti desain kustom, material berkualitas, dan harga kompetitif.
- Testimoni pelanggan.

### 2. Halaman Layanan
Menampilkan detail layanan yang ditawarkan:
- **Konsultasi dan Kustomisasi Furnitur**
- **Pengiriman dan Pemasangan**
- **Perbaikan dan Perawatan**

Setiap layanan memiliki gambar pendukung dan tombol CTA untuk informasi lebih lanjut.

### 3. Halaman Tentang
- Informasi mengenai sejarah dan visi perusahaan.
- Nilai utama perusahaan seperti kualitas, layanan pelanggan, dan keberlanjutan.
- Timeline perjalanan bisnis dari 1945 hingga sekarang.

### 4. Halaman Blog
- Artikel dan berita seputar furnitur.
- Blog populer dengan tampilan thumbnail dan judul.
- Navigasi yang mudah untuk melihat lebih banyak artikel.

### 5. Halaman Kontak
- Menampilkan peta lokasi perusahaan menggunakan Google Maps.
- Informasi kontak seperti alamat, nomor telepon, dan email.
- Formulir kontak untuk mempermudah komunikasi pelanggan.

## Teknologi yang Digunakan

- **Frontend**: HTML, CSS (Bootstrap), JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Framework CSS**: Bootstrap 5
- **Library Tambahan**: Bootstrap Icons, Google Maps API

## Tampilan dan Desain

Website ini memiliki desain yang modern dan minimalis dengan warna dominan **biru tua** dan **putih**, serta navigasi yang sederhana dan intuitif.
- **Navbar** dengan menu navigasi utama seperti *Beranda, Layanan, Tentang, Blog, dan Kontak*.
- **Footer** dengan informasi singkat tentang perusahaan, kontak, serta link media sosial.
- **Gaya responsif**, memastikan tampilan optimal di berbagai perangkat, dari desktop hingga smartphone.

## Cara Menggunakan
1. Clone repository ini ke komputer Anda:
   ```bash
   gh repo clone DanielBantjin/company-web-profile
   ```
   atau menggunakan HTTPS:
   ```bash
   git clone https://github.com/DanielBantjin/company-web-profile.git
   ```
2. Pindah ke folder proyek:
   ```bash
   cd company-web-profile
   ```
3. Jalankan server lokal menggunakan PHP:
   ```bash
   php -S localhost:8000
   ```
4. Akses website melalui browser dengan alamat:
   ```
   http://localhost:8000
   ```
